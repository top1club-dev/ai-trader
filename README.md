# AI Paper Trader (NSE)
Bot Mon-Fri market ke time (9:15-3:30 IST) GitHub Actions par apne aap chalta hai, trades `ledger.db` mein save hote hain,
report `docs/index.html` (GitHub Pages) par dikhti hai. Roz market close ke baad model naye data par seekhta hai.

Setup: repo **Public** ho -> Settings > Actions > General > Workflow permissions = Read and write -> Settings > Pages > main /docs
-> Actions tab > AI Bot > Run workflow (market ke time test).
